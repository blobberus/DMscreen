# Ambience

Each folder here is an **ambience playlist** on the DM screen: rain, a crowded tavern, wind in a cave. It is listed apart from the music in the Playlists pane and the Console, and takes a number key like any playlist (Alt+1 to 9, in folder order, music first).

**Playing:** like any playlist, its files play one after another, and starting it ends whatever was playing. To have two things at once (music with rain under it, say), start one and press the other sound's **on-top** button in the Playlists pane. The Console lists everything playing, each with its own stop button.

To add one, make a folder: on the screen, Playlists, **New** beside Ambience. A music playlist's **⋯** menu can also make it an ambience playlist, which moves its folder here.
