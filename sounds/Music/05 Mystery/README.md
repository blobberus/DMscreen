# Mystery

The **Mystery** playlist. Every audio file in this folder is one of its tracks, played in file-name order. Its number key is set on the screen.

**To add sounds:** choose **Add file**, then **Upload files**, drop in your MP3s and press **Commit changes**. They show up on the DM screen about a minute later.

Naming rules and the rest of the folders: [sounds/README.md](../../README.md)
