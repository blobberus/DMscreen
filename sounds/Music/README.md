# Music

Each folder here is a **playlist** on the DM screen, named after the folder. Its audio files are the tracks, played in file-name order.

Playlists take the number keys in folder order (Alt+1 is the first), so the `01` at the start of `01 Tavern` decides its key. You can change keys on the screen.

To add a playlist, make a folder: on the screen, Playlists, **New**.
